# 生成 SRT 与字幕同步

原片第 9877–10753 帧对应 5:29.233–5:58.467，共 877 帧。第 10754 帧切到推荐 Whisper，作为下一段的入口。

| 原片帧 | 画面与动作 |
| --- | --- |
| 9877–10077 | 灰色波形出现，红色沿播放头扫过。三段波形先后被框起，对应下方编号 155–157 及文案。说到时间戳时，每张卡补上该句的开始和结束。SRT 窗口从右入场时，前景波形滑移淡出。 |
| 10061–10385 | 右侧先出现 SRT 文本，左侧再显示教程预览。活动字幕对应红色行块，列表随句子上滚，选中行尽量保持在上方。「靠的就是 SRT」时右窗描边。下方时间线接入播放头与菱形时间点，跟随同一份字幕事件。左侧教程预览使用单独裁出的原片窗口内容。 |
| 10379–10753 | 左侧话筒和右侧三张模型卡错峰出现。三组小波形分别在第 10490、10495、10499 帧撞到各自的卡片，卡片先向右弹再左右回摆。识别节点接入后，三条文字从中间出发，分别向右上、正右、右下进入对应卡片，红叉依次转绿勾。两个工具标签先后进入。 |

时间戳与模型说明是原片演示内容。波形、时间线、卡片、SRT 文本和识别示意由代码绘制。三张卡各自调用 `ImpactRecoil`，按原碰撞时刻和测得的横向位移回摆。[三路波形撞击与回摆](../component-examples/impact-recoil/README.md) 使用同一组合。视频沿用无声预览方式。

[SRT 字幕与时间线同步](../component-examples/srt-sync/README.md) 使用相同的 `SrtSyncExample`。默认沿用教程视频的内嵌字幕与已校准的切换帧。可换入无内嵌字幕的视频，由一份毫秒级字幕时间表生成预览字幕、SRT 活动行和时间线。

[文字三路入卡](../component-examples/transcript-routing/README.md) 单独播放识别节点接入、三条文字飞向目标卡、红叉依次切换为绿勾的镜头。范例通过同一份 `SpeechRecognition` 组合替换文字和卡片内容。
