# 参考片开头 0–10 秒

参考：言说新事《实例拆解整条视频制作全流程！》 https://www.douyin.com/video/7703213715362158075

基于浏览器实际播放及保存的 0.40、1.38、2.45、2.92、3.21、3.41、4.39、4.95、5.23、5.38、6.35、7.32、8.31、8.67、8.96、9.31、10.30 秒画面。时间为观察近似值，不伪称原工程关键帧。

| 段落 | 构图及动作 |
| --- | --- |
| 0–2.55s | 左侧两行标题及橙色强调，右侧正面显示器内快速回顾上期画面；虚化拼贴背景。 |
| 2.55–3.30s | 显示器支架退去，屏幕向后倾为等距透视面板；脚本文档分离到下方。 |
| 3.30–4.35s | 成片与脚本上下保持，右侧细引线与标签出现。 |
| 4.35–5.95s | 中间依次补入素材、配音、字幕、动画四层，左侧点线标注关联各层。 |
| 5.75–6.25s | 左标题在裁剪窗口内切为“01 / 03 制作方法”，场景构图延续。 |
| 8.50–9.10s | 立体分层整体缩为左下章节缩略卡；标题切为“02 / 03 Skill 推荐”；右侧扇形卡组及 SKILL.md 标签出现。 |
| 9.10–10s | 保持第二节，图片卡组轻微稳定，左下保留第一节缩略卡。 |

实现采用 Remotion 当前帧计算；无 CSS 动画、定时器或视频回放代替主体动作。参考截图仅提供面板内部及图片卡片的静态贴图；显示器、支架、各图层、投影、引线、文字、透视和场景转换均独立绘制。排除抖音播放器、弹幕及侧栏。当前输出为无声动画。

## 抽离的组件

- `PerspectivePanel`：任意子内容的正面/等距透视投影，姿态可插值。
- `ExplodedLayers`：可替换内容、名称、进入时间和间距的分层结构。
- `SceneThumbnail`：任意场景连续缩为章节缩略卡。
- `FanCardDeck`：任意图片与文案的扇形卡组。
- `ChapterHeading`：章节编号、标题、副标题的遮罩切换。

位置、尺寸使用参考画面的 800×450 设计坐标，最终按比例渲染至 1920×1080。

## 标题交接修正

根据用户对片头大标题切到“制作方法”不连贯的反馈，实际工程改用 5.65–6.35 秒共 0.7 秒的统一交接。原先片头先退场、章节后入场，两层透明度合计一度降至约 2%；现在片头与章节以同一进度交接，合计保持 1，并将片头退场位移从 130px 缩至 12px。该修正是工程的动效调整，不追加为原片已核实的关键帧事实。

## 纸片透叠和节奏修正

最终按用户“以组件为准”的要求，撤销案例独有的 `opaquePaper` 及分层时间参数，以素材库已确认的整卡淡入和原有移动方式为唯一基准。默认时间线收进 `ExplodedLayers`，素材库不再重复声明；案例只指定 2.1 秒整体开始，素材、配音、字幕、动画由组件计算为 3.9、4.4、4.9、5.4 秒入场，每层 0.55 秒。顶部预览截图同一时间只显示一张。此前改变展开方向或单独改变透明度的方案均已撤销。
