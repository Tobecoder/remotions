# 模型对照镜头

逐点查看[原片](https://www.douyin.com/video/7703213715362158075)。约 133.9 秒仍为居中的高亮文档，135.6 秒左侧缩略文档和右侧演示就位，左下显示 Claude。约 137 秒出现 Codex，138.7 秒三个名称齐全，140.4 秒已切到“踩过的坑”。本段止于 139.5 秒。

| 工程时间 | 画面 |
| --- | --- |
| 134.08–134.82 秒 | 复用 `ContentCollapse` 把同一张文档从居中位置缩到左侧，保留文字高亮与顶部摘要。 |
| 134.34–134.94 秒 | 黑框演示窗口从右侧短距离入场，橙色点线连起两端。 |
| 135.24、136.36、137.52 秒 | Claude、Codex、DeepSeek 名称依次入场。 |
| 135.1–139.5 秒 | 右侧保留三级台面，按从右向左的顺序演出抛蛋、接住和继续抛出。 |

文档收缩和窗口入场调用已有动作组件。名称、字幕、玩偶和道具属于案例，统一由 `ScriptPlanningScene` 编排。窗口与玩偶由代码重新绘制，角色细节和个别动作轨迹为重建版本。预览从 134 秒接入该段，供人工核对节奏与造型。
