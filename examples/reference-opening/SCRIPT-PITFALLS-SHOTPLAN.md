# 提示词被略过

对照[原片](https://www.douyin.com/video/7703213715362158075)约 139.5–153.4 秒。原片从「踩过的坑」标题进入两张提示词卡，再把卡片与成片片段并排展示。工程止于 153 秒，在「原则性的要求」出现前。

| 工程时间 | 画面 |
| --- | --- |
| 139.5–140.25 秒 | 前一镜的画面淡去，原有两条顶部编号不动，左上出现「写在脚本里的提示词，被略过了」。 |
| 141.73–144.42 秒 | 「检查系统环境」横卡浮入中央，随后整体缩到左侧上方。 |
| 143.98–146.93 秒 | 「创建 Remotion 项目」竖卡在前景出现，随后缩到第一张卡下方。 |
| 148.48–151.1 秒 | 点线连向右侧黑框。框内是基础环境检查，终端逐行出现检查结果。黑框上方随后出现「Opus 直接略过」。 |
| 151.1–153 秒 | 黑框切到项目文件夹示意，红色描边与「视频里只剩几个要点」显现。 |

使用 `CardEntrance`、`ContentCollapse` 和 `HighlightBox` 编排。两张卡内容与时序留在案例中，右侧演示用代码重建。镜头衔接保留 139.5 秒之前的原有组合，出场时短暂保留前一镜末帧。原片按钮、进度条与悬浮缩略图属于播放器界面。

在 Studio 的 `10-Skipped-Prompts` 内可独立查看这 13.5 秒，也可用 `--segment 10-Skipped-Prompts` 导出。
