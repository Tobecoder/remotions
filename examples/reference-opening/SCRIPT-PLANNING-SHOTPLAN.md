# 分段动画要求：文档备注示例

按用户提供的两张截图和[原片](https://www.douyin.com/video/7703213715362158075) 2:08–2:14 的连续画面校正。第一张卡收左，第二张卡收右，分别保留自己的字号比例、文档内容和黄色备注。

| 工程时间 | 镜头 |
| --- | --- |
| 128.93 秒 | 第二问标题和顶部摘要保留，字幕换成「我是几乎不写的只在个别地方做了备注」。 |
| 129.10–130.22 秒 | 「视频模型 vs Remotion」文档在中间入场，随后高亮章节画面的备注。 |
| 130.22–130.76 秒 | 第一张缩到左下。第二张「动效库」在前景入场，第一张仍在左后方。 |
| 130.98–132.06 秒 | 第二张高亮工作台备注，然后缩向右下，与左卡并排。 |
| 132.08–132.30 秒 | 左右两张缩小的卡连同原问题标题淡去。 |
| 132.14–134 秒 | 第三张「模型与 Agent」独立入场，随后点亮黄色备注，接到 2:14 的演示对照。 |

卡片入场沿用 `CardEntrance`，缩小与平移沿用 `ContentCollapse`。`ScriptPlanningExcerpt` 负责三张文档的内容、左右落点与出场时间。布局按 800×450 的设计尺寸计算，两张折叠预览分别落在 (46, 198) 和 (409, 212)。

在 Studio 的 `08-Planning-Cards` 内可独立查看这 5 秒。画面时间根据原片观察近似取值，最终观感由预览确认。
