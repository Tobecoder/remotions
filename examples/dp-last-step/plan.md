# DP 最后一步 · 20 秒代表样片

## 用户已选择的方向

用户先要求继续做 DP 入门，参考所给教程制作约 20 秒，主要把事情讲清楚。随后选择了“浅色三维阶梯和黄色小球”的质感，以及 ByteQuest 爬楼梯动画的讲解方式，并回复“按你的来”。本期按这个已授权方向执行，不重做原来的三分钟工程。

## 讲解目标

受众为第一次接触 DP 的学习者。已知每次只能上 1 级或 2 级，用第 4 级说明：最后一步只可能来自第 3 级或第 2 级，两类互斥，因此 3 + 2 = 5。本样片只解释这个递推来源，不在 20 秒中加入代码、复杂度或整个 DP 理论。

## 画面与声音

1920×1080、30 FPS、600 帧。使用真实 Three.js 三维白色台阶、浅暖色背景、柔和阴影、金色与蓝色棋子。每颗棋子代表一种走法。金色 3 颗与蓝色 2 颗依次进入第 4 级；来源标签与终点数量有明确对应。图形和文字独立渲染，不使用装饰粒子或铺满的说明卡片。

镜头以固定轻透视/正交相机建立空间，只有小幅度推近；动作含起跳准备、抛物线、落地压缩和恢复。路径弧线在实际起跳前建立、与实际目的地对应。声音延续用户已选本机 Huihui 中文合成音，不调用付费服务；原速使用实测 WAV，实际口播超时则缩短文案而不强行变速。交付为可编辑 Studio 预览，不自动导出 MP4 或部署。

## 时间与动作

| 节拍 | 预估时间 | 内容与动作 |
| --- | --- | --- |
| 建立问题 | 0～4 秒 | 四阶台阶进入视野，强调终点第 4 级；标题问最后一步来自哪里；规则“每次走 1 或 2 级”清楚可见 |
| 第一类 | 4～8.5 秒 | 第 3 级出现 3 颗金色棋子及“3 种走法”；旁白说“再走一步”时沿弧线依次起跳并落到第 4 级 |
| 第二类 | 8.5～13 秒 | 第 2 级出现 2 颗蓝色棋子及“2 种走法”；说“再走两步”时跨过第 3 级，落到终点另外两个位置 |
| 汇合与结论 | 13～20 秒 | 两类保持不同颜色，终点共 5 颗；旁白说“三加二，等于五”时依次突出 3、2、5，最后停留完整画面 |

以上时间为计划，制作时用实际配音的词语时间调整；总长仍固定 20 秒。保留足够结尾阅读时间。

## 输入与审查

ST-005 单镜 Remotion。必需输入为 `assets/scene-spec.json` 中的事实、路径分组、形状/材质规范和字体，以及 `assets/voice-segments.json` 文案。代码、三维模型的程序构造、实际配音和字幕为制作输出，不要求用户提供外部图片。参考作品仅用于观察动作、质感和讲法，不下载或分发 Envato、Rive、YouTube 的原始素材。

## 验收

数学：金色来源对应 111、12、21，最后加 1；蓝色来源对应 11、2，最后加 2；五个完整路径互异且步长和均为 4。画面只把这些计数作为已知小问题，不宣称本片已推导出它们。

视觉：三维材质、空间、光影可见；棋子没有跳错台阶、穿过台阶或互相遮挡；来源/终点/字幕不冲突；动作落地与结果显示同步。声音：不变速；字幕使用实际 WAV 和 SAPI 时间。技术：600 帧、任意帧重算/倒向跳转一致，实际渲染检查首中末及关键接触帧。用户对风格与讲解效果的认可留待审看，不用测试结果代替。
