# Remotions

Remotion 动画素材库，当前收录 **29 个可复用组件**。包括透视、章节、分层、路径、约束和文档等动作，以及 Agent 成片流程、打字对照和卡片放大回位。单条进度、计数与分格电量、文档窗口、区域高亮、标题收拢、卡片入场、落卡回弹、撞击后回摆、文字翻转替换、前景聚焦、内容收拢和素材飞入容器均可独立组合；固定编排保存在案例工程。此前的 42 个公开动画组件和归档旧效果已移除。

保留浅色中文网站、分类切换、组件包和构建基础。新增素材按实际观察的参考样片制作，显示效果由使用者验收。旧代码可从 Git 历史查看。

组件设计、素材入库、公开导出和案例编排遵循 [组件边界约定](docs/COMPONENT-BOUNDARIES.md)。

以完整效果是否方便复用为判断标准，按已拆分组件逐项补充[完整范例](examples/component-examples/README.md)。目前十八份，新增脚本扫过与三处错词校正。各关联动作卡片均可查看原案例生成的完整预览、替换说明、保留效果和代码用法。范例不计为新的公开动作组件，新入口待用户确认。

## 本地运行

需要 Node.js 20+ 和 npm 10+。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 http://localhost:3000。版式转场收录 8 个、叙事动画 10 个、数据图表 3 个、文字特效 4 个、背景特效 1 个、信息叠加 2 个、视觉效果 1 个。桌面悬浮卡片从头播放，移出恢复展示帧；点击或键盘激活可播放/停止。其他分类显示对应的整理中提示。每张卡片提供用法示例。

此前的 24 项清单尚未完成逐项动作核实，不能作为已确认的复刻清单。见[核实更正记录](docs/reference-effects/README.md)。

最新连续时间线到 6:35.667，覆盖本地 Whisper、脚本校准和字幕宽度示例，停在下一张时间线演示前。场景与素材库共用组件实现，原片观察及分段预览见[参考片开头复原](examples/reference-opening/README.md)。

## 检查

```sh
npm run check
npm pack --dry-run -w @remotions/animations
```

`@remotions/animations` 导出上述二十九个组件。独立视频示例保留在 `examples/`；固定业务编排位于 `examples/reference-opening/compositions/`，不列入素材目录或组件包公开 API。现有视频制作规划保留于 `docs/`，其中旧组件数量及能力记录属于历史状态。
