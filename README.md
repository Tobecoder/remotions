# Remotions

Remotion 动画素材库，当前收录 **25 个可复用组件**。包括透视、章节、分层、路径、约束和文档等动作，以及素材准备、Agent 成片流程、打字对照和卡片放大回位。单条进度、文档窗口、区域高亮、标题收拢、卡片入场、前景聚焦和内容收拢均可独立组合；脚本文档讲解、进度对比、五卡文档聚焦和小节摘要的固定编排保存在案例工程。此前的 42 个公开动画组件和归档旧效果已移除。

保留浅色中文网站、分类切换、组件包和构建基础。新增素材按实际观察的参考样片制作，显示效果由使用者验收。旧代码可从 Git 历史查看。

组件设计、素材入库、公开导出和案例编排遵循 [组件边界约定](docs/COMPONENT-BOUNDARIES.md)。

## 本地运行

需要 Node.js 20+ 和 npm 10+。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 http://localhost:3000。版式转场收录 8 个、叙事动画 9 个、数据图表 2 个、文字特效 3 个、背景特效 1 个、信息叠加 2 个。桌面悬浮卡片从头播放，移出恢复展示帧；点击或键盘激活可播放/停止。其他分类显示对应的整理中提示。每张卡片提供用法示例。

此前的 24 项清单尚未完成逐项动作核实，不能作为已确认的复刻清单。见[核实更正记录](docs/reference-effects/README.md)。

可看[参考片开头复原](examples/reference-opening/README.md)，原有各时长版本保留；最新连续版本为 96 秒，补齐脚本章节，停在“还是重点聊两个大家比较关心的问题”字幕处。场景与素材库共用组件实现，原片观察及复原边界见该示例目录。

## 检查

```sh
npm run check
npm pack --dry-run -w @remotions/animations
```

`@remotions/animations` 导出上述二十五个组件。独立视频示例保留在 `examples/`；固定业务编排位于 `examples/reference-opening/compositions/`，不列入素材目录或组件包公开 API。现有视频制作规划保留于 `docs/`，其中旧组件数量及能力记录属于历史状态。
