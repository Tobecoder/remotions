# Remotions

Remotion 动画素材库，当前收录 **5 个可复用组件**：透视面板、分层展开、章节缩略卡、扇形卡组、章节标题切换。此前的 42 个公开动画组件和归档旧效果已移除。

保留浅色中文网站、分类切换、组件包和构建基础。后续仅加入按参考样片制作、通过实际视觉确认的素材。旧代码可从 Git 历史查看。

## 本地运行

需要 Node.js 20+ 和 npm 10+。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 http://localhost:3000。版式转场收录 3 个、叙事动画 1 个、文字特效 1 个。桌面悬浮卡片从头播放，移出恢复展示帧；点击或键盘激活可播放/停止。其他分类显示对应的整理中提示。每张卡片提供用法示例。

此前的 24 项清单尚未完成逐项动作核实，不能作为已确认的复刻清单。见[核实更正记录](docs/reference-effects/README.md)。

可看[开头十秒复原](examples/reference-opening/README.md)，该场景与素材库共用上述五个组件。目录中的独立演示用原创内容，不依赖原片贴图；原片观察及复原边界见该示例目录。

## 检查

```sh
npm run check
npm pack --dry-run -w @remotions/animations
```

`@remotions/animations` 当前没有动画导出。独立视频示例保留在 `examples/`，不属于素材库；旧教程中对已删除组件的引用已解除。现有视频制作规划保留于 `docs/`，其中旧组件数量及能力记录属于历史状态。
