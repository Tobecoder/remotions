# Remotions

Remotion 动画素材库，当前收录 **16 个可复用组件**。在透视面板、分层展开、章节缩略卡、扇形卡组、章节标题切换、虚化拼贴漂移、音效脉冲徽章、章节卡总览、多路径演示、小节收束的基础上，新增靶心归位、约束开关、绳索牵回、曲线上升、文档聚焦和限制解除。此前的 42 个公开动画组件和归档旧效果已移除。

保留浅色中文网站、分类切换、组件包和构建基础。新增素材按实际观察的参考样片制作，显示效果由使用者验收。旧代码可从 Git 历史查看。

## 本地运行

需要 Node.js 20+ 和 npm 10+。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 http://localhost:3000。版式转场收录 5 个、叙事动画 7 个、数据图表 1 个、文字特效 1 个、背景特效 1 个、信息叠加 1 个。桌面悬浮卡片从头播放，移出恢复展示帧；点击或键盘激活可播放/停止。其他分类显示对应的整理中提示。每张卡片提供用法示例。

此前的 24 项清单尚未完成逐项动作核实，不能作为已确认的复刻清单。见[核实更正记录](docs/reference-effects/README.md)。

可看[参考片开头复原](examples/reference-opening/README.md)，保留十秒、二十秒及第一点完整版本，连续版本已接完第二点，停在 52.5 秒的“开工之前”标题页；场景与素材库共用上述十六个组件。目录中的独立演示用原创内容，不依赖原片贴图；原片观察及复原边界见该示例目录。

## 检查

```sh
npm run check
npm pack --dry-run -w @remotions/animations
```

`@remotions/animations` 导出上述十六个组件。独立视频示例保留在 `examples/`；旧教程中对已删除组件的引用已解除。现有视频制作规划保留于 `docs/`，其中旧组件数量及能力记录属于历史状态。
