# Text Effects fonts

The catalog uses the same Latin typefaces as the Remotion Elements references:

- Cormorant Garamond 700, from Google Fonts (`fonts.gstatic.com/s/cormorantgaramond/v21/co3umX5slCNuHLi8bLeY9MK7whWMhyjypVO7abI26QOD_hg9GnM.ttf`). License: `CormorantGaramond-OFL.txt`.
- Mona Sans 700, from Google Fonts (`fonts.gstatic.com/s/monasans/v4/o-0mIpQmx24alC5A4PNB6Ryti20_6n1iPHjcz6L1SoM-jCpoiyAaBN9d.ttf`). License: `MonaSans-OFL.txt`.

These SIL Open Font License assets are served locally by the catalog and are not included in the animations npm package. Consumers load their own fonts before rendering. Chinese text uses the host's serif/sans-serif fallback fonts.
