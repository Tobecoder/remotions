## R01 的当前范围

复看原片 02:13 暂停画面：浅纸底、居中白文档、柔和投影、淡黄色段落重点及侧边色标。首版用原创演示文档替换原片内容，保留平面卡片结构，不额外加入三维旋转、粒子或装饰图形。

候选动作固定为：0–0.85 秒进入；1.25–1.95 秒高亮；2.6–3.75 秒轻推聚焦；之后停留。它是参考画面指导的首版实现，尚未认定与原片运动完全一致。

两份演示内容共用同一组件，验证换图与换重点区域。组件暂存于 `packages/animations/src/drafts/`，不从公共入口导出；正式素材清单仍为空。页面的“待验收”区负责审看。

## 调用约定（候选）

`ScreenshotFocusDraft` 输入为 `src`、原图宽高 `imageWidth` / `imageHeight`、相对重点区域 `focus`。`focus` 的 x/y/width/height 在 0–1 内；不拉伸截图，不用 CSS 动画或墙钟时间计算。

本轮不复制原片视频、人物或原始图片作为库素材；原片链接与定位用于对照。技术检查与用户的视觉认可分别记录。
