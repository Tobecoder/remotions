# 组件边界约定

本约定用于动画组件设计、素材入库、组件拆分及组合迁移。新增素材的判断标准是：**它能否脱离当前脚本，直接用于另一条视频。**

## 职责归属

| 位置 | 职责 |
| --- | --- |
| `packages/animations/src/` | 提供可独立调用的动作，例如文档窗口、区域高亮、标题收拢和单条进度。 |
| `apps/catalog/src/` | 为独立组件提供分类、预览和用法；演示内容通过组件参数或插槽提供。 |
| `examples/<项目>/compositions/` | 组合动作、安排镜头与时间、填入业务文案和数值，支撑具体成片。 |

## 入库条件

- 动作可以独立调用，调用方可以替换所需文案、素材或数值。
- 动作进度、开始时刻或播放时间由调用方控制，能够适应另一条视频的节奏。
- 位置、尺寸、颜色和内容按实际复用需求提供参数或插槽，保持接口简洁。
- 特定讲解顺序、跨多个动作的固定时间线、业务结论和场景文案归案例工程。
- 一个动作内部可以组合多个元素；按它是否能独立复用判断归属，避免只因内部元素较多就继续拆分。

## 素材目录与公开 API

- 素材目录与组件包公开入口只登记符合入库条件的组件，组件名称、分类、用法和导出保持一致。
- 固定业务组合及其专属类型留在案例工程，退出素材目录及 `packages/animations/src/index.ts`、`packages/animations/src/reference-opening/index.ts` 两处入口；不通过库入口提供兼容别名。
- 组件库和素材站不反向依赖案例中的组合代码。案例从组件库调用独立动作。

当前示例中的 `ScriptDocumentGuide`、`ProgressRace` 位于 `examples/reference-opening/compositions/`，分别编排文档讲解和快慢进度对比；它们不属于素材目录或组件包公开 API。

## 修改与迁移

1. 先检查已有组件和调用方，确定要复用的独立动作以及属于案例的编排。
2. 相同动作复用素材组件的实现；案例负责传入内容与时间，避免另写一套动作导致效果漂移。
3. 拆分或迁移时保留已确认的动画方向、最终位置和节奏；视觉调整按当次用户要求执行。
4. 组合退出素材库时，一并迁移案例引用，清理目录、预览分支、运行时导出、类型导出和用法说明。
5. 按改动范围验证独立调用、目录与导出一致性、原案例运行及动作衔接。构建和数值检查与视觉验收分别说明；仅文档改动检查内容和引用即可。

现有组件按实际复用需求逐项评估，本约定不授权批量删除其他组件或改写已确认的成片。
