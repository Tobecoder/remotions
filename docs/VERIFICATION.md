- React 交互测试覆盖分类方向键与 Home/End、鼠标悬浮/点击、触摸点击两次播放/停止、键盘聚焦后停止/恢复预览；测试中的卡片预览句柄使用轻量替身，真实 Remotion Player 的跨浏览器验收仍需手工执行。
